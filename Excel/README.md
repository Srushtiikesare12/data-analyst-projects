# 📗 Excel Projects

This section contains hands-on Excel projects developed to build practical Data Analytics skills.

The projects focus on data cleaning, analysis, formulas, lookup functions, data validation, pivot-based analysis, dashboards, and business insights.

Each project demonstrates the practical application of Excel to transform data into meaningful information and support data-driven decision making.
