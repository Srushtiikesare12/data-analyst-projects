College Performance & Fees Analytics

Project Overview

This project uses MySQL to analyze student enrollment, course-wise fee collection, pending fees, examination results, and overall academic performance at a fictional college.

Objectives

- Analyze student enrollment across courses.
- Calculate course-wise fee collection and pending fees.
- Identify students with pending or partially paid fees.
- Analyze examination results and subject-wise performance.
- Calculate course-wise pass percentages.
- Identify top-performing students.
- Rank courses based on fee collection.

Tools Used

- MySQL
- MySQL Workbench
- SQL

Database Structure

The project uses six tables:

1. "students" – Student details
2. "courses" – Course information
3. "enrollment" – Student enrollment records
4. "fees" – Fee payment details
5. "subjects" – Subject information
6. "results" – Examination marks and result status

Business Analysis

The project answers 12 business questions covering:

- Course-wise student enrollment
- Course-wise fee collection
- Pending fee analysis
- Unpaid and partially paid fees
- Average student age by city
- Enrollment status analysis
- Course-wise average marks
- Subject-wise average marks
- Failed students by subject
- Course-wise pass percentage
- Top-performing students
- Course ranking by fee collection

Key Insights

- BCA and MCA have the highest enrollment, with 4 students each.
- MBA has the highest fee collection at ₹1,80,000.
- BCA and MBA have average marks above 60.
- Aditya Kulkarni ranks first among the top-performing students, with an average score of 91.
- BBA has the lowest fee collection at ₹1,00,000.
